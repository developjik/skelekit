# SkeleKit — Product Steering

## What this is
SkeleKit is a **spec-driven skeleton template** for building deployable web apps with Kiro.
One lean foundation (`template/`) spawns distinct applications. Every app in this repo is
generated by Kiro agents executing the specs under `.kiro/specs/` — never hand-copied code.

## Why it exists (Kiroween 2026 — Skeleton Crew category)
A skeleton should be *lean enough to be clear* yet *flexible enough to spawn very different
apps*. We prove versatility by shipping **two deliberately different applications** from the
same foundation:

1. **Grave Dash** — a spooky one-button arcade game (canvas, fixed-timestep loop).
2. **OppBoard** — a deadline-tracking dashboard for dev opportunities (DOM, router, data table).

If a game engine and a productivity board can both grow from the same bones, the skeleton works.

## Product principles
1. **Specs are the source of truth.** Code follows `.kiro/specs/*/tasks.md`. No feature exists
   without a task; no task without a requirement.
2. **Lean beats clever.** Zero runtime dependencies. Everything the template provides must fit
   in a developer's head in ~15 minutes.
3. **Apps own their personality.** The foundation provides mechanics (state, routing, loop,
   DOM helpers); apps provide identity (theme tokens, content, screens).
4. **Deployable by default.** `npm run build` in any app produces a static bundle that runs on
   GitHub Pages with no server.

## Non-goals
- No framework (React/Vue/etc.), no bundler magic beyond Vite, no backend, no auth.
- Not a monorepo toolkit: the template is copied/scaffolded per app, not installed as a package.
